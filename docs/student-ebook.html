الصفحة الأولى للطالب

  • تظهر تحية باسم الطالب عند تسجيل الدخول.
  • لوحة تقدم فيها عدد الدروس المكتملة والتسليمات وتقييمات المعلم.
  • قسم النقاط والمستوى الحالي والهدف القادم.
  • بطاقات الموضوعات موزعة على فصلين.
  • كل بطاقة تعرض حالة الدرس والتسليم والتقييم.

عناصر الصفحة الفعلية

  • مرحباً، [اسم الطالب] أو عنوان "الموضوعات" إذا لم يوجد تسجيل دخول.
  • لوحة التقدم مع زر عرض لوحة النقاط.
  • موضوعات الفصل الأول وموضوعات الفصل الثاني.
إذا أغلق المعلم الدرس، فإن زر "عرض الدرس" يظهر معطلًا ومصحوبًا بعبارة "غير متاح حاليًا".

صفحة الدرس

قبل البدء

عنوان الدرس، وصف مختصر، وبطاقة أهداف مع زر "ابدأ الدرس".

بعد الضغط على ابدأ الدرس

تظهر مقدمة الدرس، الفيديو التوضيحي، خطوات الدرس، ثم قسم أنشطة هذا الدرس.

الانتقال إلى النشاط

زر النشاط لا يذهب إلى التطبيق مباشرة، بل يذهب أولًا إلى صفحة شرح النشاط ثم إلى التطبيق.

الانتقال إلى المراجعة

في نهاية الدرس يوجد زر "الانتقال إلى مراجعة الدرس". عنده تُحتسب نقاط إكمال الدرس.

صفحة شرح النشاط

  • تعرض خطوات النشاط بصريًا في صفحة مستقلة.
  • فيها stepper يتيح الانتقال بين الخطوات.
  • فيها عرض توضيحي متحرك أو مثال مرئي.
  • فيها أزرار السابق، التالي، إعادة التشغيل، وتشغيل تلقائي.
  • فيها زر العودة إلى الدرس وزر ابدأ النشاط.

النصوص الأساسية الظاهرة

  • شرح النشاط: [اسم الدرس]
  • شاهد الخطوات بشكل بصري، ثم انتقل إلى التطبيق الحقيقي.
  • العودة إلى الدرس / ابدأ النشاط / السابق / إعادة التشغيل / تشغيل تلقائي / التالي
هذه الصفحة هي "الأنيميشن" أو الشرح البصري الذي يسبق التطبيق العملي لكل نشاط مدعوم.

أنواع الأنشطة وكيف تعمل

المحطات

الطالب ينتقل بين مراحل أو صور أو مشاهد.

الاختيار

يسحب الإجابة أو يضغط عليها لتوضع في المكان الصحيح.

التقدم

يظهر شريط تقدم، وفي بعض الأنشطة مؤقت زمني.

المسودة

بعد اكتمال الاختيارات تُنشأ مسودة يمكن تعديلها.

بطاقات قابلة للتحريك

يتم ترتيبها باستخدام أعلى وأسفل.

تحرير النص

يمكن تعديل البطاقة نفسها وليس فقط ترتيبها.

مسودة نهائية

يتم جمع البطاقات داخل منطقة تحرير نهائية.

إعادة الترتيب

يمكن الرجوع للوضع الأصلي ثم المحاولة من جديد.

اختيار محفز

صورة أو قضية أو سيناريو أو موضوع حر.

معاينة

يرى الطالب تفاصيل المحفز قبل الكتابة.

ثلاث مراحل

اختيار، معاينة، كتابة.

إرسال مباشر

في النهاية يرسل التعبير ويحفظ في النشاطات.

مناقشة قضية

الطالب يختار قضية أو مجموعة ثم يدخل غرفة نقاش جماعي.

النص الحواري

الطالب ينتظر مطابقة مع زميل ثم يبدأ الحوار الثنائي.

غرف محادثة

يظهر سجل حي للمحادثة داخل النشاط نفسه.

اكتمال تعاوني

يُسجّل النشاط في سجلات الإنجاز التعاوني.

النشاطات التطبيقية في الكود الحالي تشمل: scene-choice وassemble وfree expression وcollaborative discussion وpeer dialogue.

قراءة الشاشة

كيف يقرأ الطالب الواجهة؟

1. يبدأ من الموضوعات

يقرأ لوحة التقدم، ثم يختار بطاقة موضوع عبر زر عرض الدرس.

2. يتعلم قبل أن يكتب

صفحة الدرس ليست مكان التسليم؛ هي مكان الفهم، ثم يأتي بعدها شرح النشاط، ثم التطبيق.

3. النشاط منفصل عن الشرح

الشرح البصري في صفحة مستقلة، ثم التطبيق في صفحة أخرى، وهو التدفق الذي طلبته في المشروع.

4. النهاية ليست عند الإرسال

بعد التقييم تظهر التسليمات، النقاط، والتغذية الراجعة اللاحقة من المعلم.

هذا الفصل هو المرجع الأسرع إذا أردت رؤية البنية الفعلية للواجهات بدل قراءة وصف عام فقط.

الفصل 7

كل صفحات الطالب ومسار استخدامها

هذا الفصل يجمع الصفحات الظاهرة للطالب في المشروع الحالي، من لحظة الدخول حتى الكتابة والتقييم والنقاط والدردشة.

/login

صفحة الدخول الأولى قبل إظهار شريط التنقل وصفحات الطالب الخاصة.

/

الموضوعات، لوحة التقدم، بطاقات الفصل الأول والثاني، وزر عرض الدرس.

/topic/:topicId

صفحة الدرس وفيها الأهداف والمقدمة والفيديو والخطوات والأنشطة.

/activity/:topicId/tutorial

الشرح البصري المنفصل الذي يسبق التطبيق العملي للنشاط.

/activity/:topicId/task

صفحة التطبيق نفسها: اختيار، ترتيب، كتابة، أو نشاط تعاوني بحسب نوع الدرس.

/lesson-review/:topicId

ملخص الدرس، نموذج الكتابة، والمساعد الذكي قبل بدء المهمة الكتابية.

/evaluate/:topicId

كتابة النص، تشغيل التقييم، والانتقال إلى صفحة النتائج والكتابات السابقة.

/my-submissions

كل كتابات الطالب وتقييماته وسجل أنشطته ودروسه.

/student-progress

لوحة النقاط والإنجازات والمستوى والهدف القادم.

/chats + /profile

الدردشة مع المعلم أو المشرف ثم الملف الشخصي وبيانات الحساب.

دخول ← موضوعات ← درس ← شرح ← تطبيق ← مراجعة ← تقييم ← تسليمات / نقاط / دردشة
15
استخدام يومي

كيف يتحرك الطالب خلال الرحلة كاملة؟

1. اختيار الدرس

يبدأ من / ويقرأ لوحة التقدم ثم يضغط عرض الدرس على البطاقة المناسبة.

2. الفهم قبل التطبيق

داخل /topic/:topicId يقرأ الشرح والخطوات، ثم يضغط نشاط الدرس ليذهب إلى /activity/:topicId/tutorial.

3. الشرح ثم العمل

بعد مشاهدة الخطوات بصريًا يبدأ النشاط من /activity/:topicId/task، ثم ينتقل إلى /lesson-review/:topicId.

4. الكتابة وما بعدها

يكتب في /evaluate/:topicId ثم يراجع نتائجه في /my-submissions ويرى نقاطه في /student-progress.

5. الدعم الشخصي

إذا احتاج مساعدة يستخدم /chats، وإذا أراد بياناته الشخصية ينتقل إلى /profile.

بهذا يكون الكتاب قد غطى كل صفحة طالب ظاهرة في المشروع الحالي، مع ترتيبها الفعلي في الرحلة.

الملحق

تسليماتي والنقاط والملف الشخصي

  • صفحة "تسليماتي" فيها تبويبان: الكتابات والتقييمات، وسجل الأنشطة والدروس.
  • صفحة مراجعة التسليم تعرض نص الطالب ثم تحليل AI ثم تقييم المعلم عند توفره.
  • صفحة النقاط تعرض إجمالي النقاط، الهدف القادم، المستويات والمكافآت.
  • الملف الشخصي يعرض الاسم والصف والبريد والدور وآخر ملاحظات الذكاء الاصطناعي.
  • مركز الدردشة يربط الطالب بمعلمه أو بالمشرف إذا كانت الدردشة متاحة.
